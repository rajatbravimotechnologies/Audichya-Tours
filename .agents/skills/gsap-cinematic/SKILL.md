# GSAP Cinematic Animation

Use GSAP and ScrollTrigger for:

- scroll-driven storytelling
- camera movement
- object movement
- text transitions
- section transitions
- pinned scenes

Prefer a master timeline for coordinated sequences.

Use gsap.context() for React cleanup.

Prevent duplicate ScrollTriggers.

Use scrub where appropriate.

Use smooth easing.

Avoid excessive animation.

Never animate everything simultaneously.

Prioritize:

1. Story
2. Camera
3. Hero object
4. Environment
5. Text
6. UI
